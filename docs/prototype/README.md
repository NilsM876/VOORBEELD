# docs/prototype/

Screenshots or images of your user interface prototype: the screens of the must-haves
and how you move between them. Name them in order, for example `01-start.png`,
`02-search.png`.

The link to the prototype itself goes in the README in the project root.
Nothing else from the prototype goes into this repository.

## Screenshots van Sharply

1. `01-start.png`: de startpagina. Je vult per aandeel een ticker, rendement,
   standaarddeviatie en bedrag in (user story 1).
2. `02-resultaat-en-leaderboard.png`: na het invullen verschijnen rendement,
   volatiliteit en Sharpe ratio (story 2) en de optimale weging (story 3).
   Onderaan staat het leaderboard met de hoogste Sharpe ratio bovenaan (stories 4 en 5).
3. `03-portefeuille.png`: via "Portefeuille bekijken" op het leaderboard kom je op de
   pagina van een andere belegger. Die zie je pas volledig na de gesimuleerde betaling
   van €5; daarna kun je commentaar plaatsen (stories 6 en 7).
